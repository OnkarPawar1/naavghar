About this collection

The complete imported collection contains 711 + 500 + 630 = 1,841 source entries. Similar names and repetitions remain in the database intentionally, because each source entry belongs to the original material. List C did not provide Marathi spellings; where a matching Marathi spelling was unavailable from Lists A and B, a suggested phonetic Marathi rendering is shown and marked “Suggested spelling”. Please verify such spellings and meanings before using them officially. Source texts may contain inconsistencies.
